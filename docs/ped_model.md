# 歩行者モデル sfm2(Moussaïd 型の先読み Social Force)

`social_nav_sim --ped-model sfm2` で選ぶ(既定は sfm2。design 6.2)。実装は `social_nav_core/sim/ped_model.{hpp,cpp}`、家族・歩きスマホの付与は `sim/ped_variants.{hpp,cpp}`(crowd だけ)。旧モデル(legacy = `SocialForceWorld`)は無変更。

## 1. 式
歩行者 i の加速度 a_i = 駆動 + 相互作用 + 接触 + 壁 + 群れ(家族のみ) + OU 雑音。

- 駆動: (v0·e − v)/τ。τ = 0.5 s。到達(目標まで 0.3 m 未満)後は速度 0 で停止(漂わない)。個人の速さは min(2.0 m/s, speed_cap·v0) に制限(speed_cap = 1.1。調整 2 で追加)。
- 相互作用(Moussaïd 2009/2010 の形): i から見た j の方向 e_ij、D = λ(v_i − v_j) + e_ij、t = D/|D|、θ = t から e_ij への角、K = sign(θ)、B = γ|D|。
  f = −A·exp(−d/B)·[ exp(−(n'Bθ)²)·t + exp(−(nBθ)²)·K·n_t ](n_t は t の左法線)。ロボットは `robot.vel` を持つ 1 エージェントとして j に加える。打ち切り 6 m。注意係数(通常 1)を掛ける。さらに j が視野外なら重み c = rear_weight(0.65)を掛ける。視野は目標方向(速度ではない)の ±fov/2(fov 200°)の階段型で、視野内は 1(調整 3)。
- 接触: 体の重なりにばね k = 500 1/s²(legacy と同じ)。壁: A_wall·exp((r−d)/B_wall) + ばね(A_wall 3.0、B_wall 0.3)。
- OU 雑音(加速度に加える): σ = 0.3 m/s²、相関時間 0.5 s。専用 engine(mt19937、seed+4242)から歩行者の配列順に毎ステップ 4 個の生出力を引き(1 人 2 個の標準正規)、一様/正規への変換は自前(Box-Muller。std の distribution は使わない)。
- 群れ(group_id が同じ者だけ。Moussaïd 2010 の視線・凝集・群内斥力): 重心が視野(全角 100°)の外なら進行方向を重心側へ向ける横加速度(係数 1.0)、重心距離が 0.7·(N−1)/2 + 0.4 m を超えたら重心へ(係数 3.0)、0.6 m 未満の仲間から離れる(係数 3.0)。群内では相互作用に 0.3 を掛ける。
  - **視線と K の 2 式併存(屋内の群れ、暫定):** 上の視線の式(横加速度)と K 込みの相互作用は `group_id < 100`(crowd の 0..2)の式である。`group_id >= 100`(`group_oncoming`。閾値は `kPaperGazeGroupIdMin`)では、視線は速度に沿う減速 −β(|α| − 視野半角)V(β = 1.0)にし、同じ群れの仲間どうしの相互作用から K の項を除く。別の群れ、ロボット、接触、壁、凝集、群内斥力は共通。統一するかは判定 21–120 を回すときに決める。
  - **論文との差(屋内の群れ):** 論文の形にしたのは視線項の向き(減速)だけである。係数は β = 1.0(論文の現実的な値は 4)、視野は全角 100° = ±50°(論文は ±90°)、重心は自分を含む。
- 歩きスマホ(kind = 2): v0 × 0.8、注意係数 × 0.4、雑音 × 2。

## 2. 出典と確認状況
確認できなかったものは「未確認」。係数はすべて PedParams(`ped_model.hpp`)に集約。
- Moussaïd, Helbing, Theraulaz (2009) Proc. R. Soc. B(相互作用の式、A = 4.5、γ = 0.35、n = 2、n' = 3、λ = 2.0、τ = 0.5): **未確認**(原論文を取得できなかった。記憶ベース)。
- Moussaïd et al. (2010) PLoS ONE 5(4): e10047(家族の群れ): PLoS の本文 HTML を取得して**構造のみ確認**(視線の回転・重心への凝集・重なり時の群内斥力の 3 項、群のサイズで重心距離の閾値が増える、「現実的な値 β = 4」)。数式の記号が HTML から落ちており、凝集・斥力の係数値、視野角、閾値の式は**未確認**。sim の群れ係数は文献値ではなく、家族が崩れないよう置いた初期値。
- Weidmann (1993) Transporttechnik der Fussgänger(速度–密度。v = 1.34(1 − exp(−1.913(1/ρ − 1/5.4)))): 出典としての参照は確認。式の係数は**未確認**(記憶ベース)。ρ = 0.5 / 1.0 / 1.5 人/m² で 1.30 / 1.06 / 0.81 m/s(計画の基準値は 1.30 / 1.06 / 0.80)。
- 視野外の重み(fov 200°、c = 0.5 を基準に 0.65 へ): Helbing & Molnár (1995) の異方性の形。値は**未確認**(記憶ベース)。Johansson (2007) の余弦型は採らず階段型にした。
- 壁項・歩きスマホの係数・雑音・speed_cap: 文献の定量値なし。初期値で、動画を見て決める(ユーザー決定)。

## 3. 実測(ped_probe。ロボットなし、seed 1001–1020)

## 5. 再現性の条件
- 同じ Docker イメージ(ID)と同じコミットなら、同じ seed で trace・CSV はバイト一致する。ctest `sim_repro_sfm2_trace` が sfm2 の crowd を seed 1 で 5 s、2 回走らせて trace の一致を確かめる(同じ環境内の確認)。
- CPU アーキテクチャやコンパイラ、標準ライブラリが違えば一致は保証しない(浮動小数の超越関数・FMA の扱いが違う)。シナリオ生成の `std::normal_distribution` などもライブラリ依存。
- 記録: `tools/run_sim_eval.sh` の conditions.txt と `tools/run_ped_probe.sh` の出力に git SHA(`social_nav_core/` が dirty なら `-dirty`、git_dirty 行も)、Docker イメージ ID(ホスト側で取得。イメージは build のたびに ID が変わる)、`uname -m`、コンパイラのバージョンを出す。
- sfm2 の乱数は専用 engine(seed+4242)だけから引き、rng / sense_rng の消費数は legacy と同じ。
